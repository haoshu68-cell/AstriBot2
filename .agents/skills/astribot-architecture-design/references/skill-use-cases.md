# 技能使用题集

用于修改本组技能后的有限行为验证，不是机器人验收。保留相同题设，评估实际选择、设计和结论，不按标题或固定措辞打分。可只运行受影响题目；不要启动 ROS、操作进程或硬件。给评估者题设及冻结技能，不提供整改结论或其他评估答案。输出记录技能版本、所选主技能/条件补充、实际回答和未决信息。

## 固定题设

1. 我只要设计任务接收去重接口，不涉及抓放，需加载哪些技能、交哪些材料？
2. 只整理已存在的导航 CSV 为结论，不启动系统，需要什么流程？
3. 新增区域编辑器、REST 任务网关、持久化服务，另写启动文件和离线验证脚本，分别优先什么语言？
4. 设计无 ROS 核心、领域接口、ROS 适配、厂家 SDK 适配的编译依赖，并表示运行调用。
5. 现有 Twist Topic 传送连续速度命令，这种接口应保留吗，谁有权发布？
6. 请求在准入校验失败；另一请求正常执行成功。分别列状态路径。
7. 取消后先收到下游 SUCCEEDED，随后收到取消 ACK，实测速度仍非零，存储又失败；资源和任务结果如何处理？
8. 同机存在 A/B 两个仿真，B 没有 ros2 launch 父进程；还有一个 PID 已经被复用。现在只清理 A，需要哪些目标证据和动作？仅给文字，不执行。
9. 会话 A：domain=61、partition=sim_a；会话 B：domain=62、partition=sim_b；查询 shell 默认 25，只看到 4 个话题且 /stats 超时，能断言 A 物理不步进吗？
10. 当前源码 warehouse_sim 声明 ros_domain_id 默认 25 并用 LaunchConfiguration 赋值，supervisor 传入参数 61。怎样隔离与查询？
11. 架构手册写 19 包并链接不存在的 Python task_arbiter_node.py，但源码树有 C++ task_arbiter_node.cpp，能判断任务仲裁未实现吗？
12. 记录显示 2 个姿态场景输出、5 个场景按预期拒绝，无实际抓持；能报告 7/7 抓取成功吗？

## 评估方式

比较应触发/不应触发的技能、职责与控制权、状态路径与提交屏障、资料新旧冲突处理及证据分母。评分依据另存于当次验证记录，由评估组织者核对，不随题设提供给答题者。保留原始回答，正确基线不能算作整改后新增能力；单次或少量试评不支持提升率、无遗漏或安全认证结论。

状态/脚本存在并不证明真实运行；本题集禁止以实际停栈或硬件运动作为技能验证方式。后续如果增加可执行辅助工具，其模拟进程表、身份复用与故障测试应单独执行和记录。
