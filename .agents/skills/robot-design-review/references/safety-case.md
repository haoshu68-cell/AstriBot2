# 安全论证与标准适用性

仅在方案涉及 SSM、人员协作、移动安全或明确合规宣称时读取。工程危险源分析与法规/认证判定分开。

记录应用类型、国家/地区（法律问题时）、人员类别、公众可接近性、移动/操作模式、载荷/工具、预期用途与可预见误用。信息缺失时缩小结论，不默认所有轮式双臂机器人都适用工业机械臂的同一标准。

标准表字段：`standard_id / edition / status_checked_at / official_source / application_scope / exclusions / requirement_reference / source_access / relevant_subsystem / evidence / gap`。
官方摘要只支持版本和范围，未取得正文的要求写“待条款核实”；不得编条号、PL/SIL、认证结论或把企业惯例当法规。

2026-09-22 检索线索：[ISO 10218-1:2025](https://www.iso.org/standard/73933.html) 面向工业机器人，其公开范围对移动平台运动等存在排除；[2011 页面](https://www.iso.org/standard/51330.html) 标注已撤销并指向 2025 版。这是候选资料，不是本项目适用性裁定。后续执行需重新核对版本和适用范围，不能用一份机械臂标准覆盖整机移动危险。

对每个危险源建立记录：

| 字段 | 必填内容 |
|---|---|
| H-id 与模式 | 导航/取放/携物/恢复/维护/人工接管，危险区域和受影响对象 |
| 触发链 | 传感缺失、延迟、错误估计、执行偏离等如何导致碰撞、夹伤、跌落或失稳 |
| 风险控制 | 预防、检测、停止/保持；每项措施的实现者、依赖、独立性及共因故障 |
| 时间/空间预算 | 检测、传输、计算、执行响应、制动/残余运动、不确定性；实测还是假设 |
| 可验证断言 | 测量工具、工况、负载、反应时间/距离界限、失效及人工恢复条件 |
| 证据和残余风险 | 源码/测试/实测的范围，缺少的硬件能力，剩余问题及负责人角色 |

SSM 论证至少考虑人员与机器人相对运动、机械臂/负载扫掠、感知覆盖、响应链、制动和定位不确定性。只有距离阈值或 ROS 心跳不足以证明保护有效；这里不提供未经本机验证的数值或宣称完整标准公式。
软件报警确认不解除物理故障锁存；软停、设备停、急停及保载后续状态分别核对。机械臂、底盘和重物共享供电/感知时，也要检查所谓独立保护是否存在共因失效。

交付为“适用性待确认 / 工程风险控制设计 / 实测证据缺口”。真机验收、认证和专业签署不因技能评审完成而自动完成。
