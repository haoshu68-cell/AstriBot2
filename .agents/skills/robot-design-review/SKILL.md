# 机器人方案评审

依据用户提供的 Doubao 评审思路重写的项目技能；公开镜像核查和改编边界见
[来源与接入记录](../../../docs/ROBOT_REVIEW_SKILLS_INTEGRATION_20260922.md)。不依赖 Doubao 服务。

## 评审范围

默认只读待评方案、代码和证据，可以生成独立评审报告；不静默修改被评文件、参数、账本或运行栈。
用户同时要求整改时，先保存评审结论，再在原授权范围内实施，不把评审模式变成重复审批。

1. 确认目标能力、部署环境、基线、非目标和验收指标。工程复用不因“缺乏论文新颖性”而扣分；仅在用户要求研究创新时查新。
2. 固定文档与代码版本、工作区改动和关键文件哈希；运行证据另记安装产物/模型/参数哈希。阅读日期新不表示证据对应当前代码。
3. 只加载相关领域技能：任务用 `robot-task-intake-execution`，运输用 `robot-task-orchestration`，数据接口用 `robot-dataflow-module-design`，安全用 `ros2-control-hardware-safety`。
4. 对关键方案比较现有基线、候选和最小改动替代项，说明解决的需求、代价、适用工况、失败方式及重审条件。无数据项标为未知。

## 两种评审视角

- **硬伤视角**：找可破坏需求或安全不变量的具体反例，检查控制权、取消屏障、版本/时效、失效恢复、可观测性及资源预算。
- **论证视角**：用 [robot-argument-audit](../robot-argument-audit/SKILL.md) 核查前提、推理和证据；它可以支持方案，也可以否定方案，不是辩护方。

需要双视角时，先分别记录意见，再合并。使用单个评审者顺序完成时标明“同一评审者的两个视角”；只有实际独立评审才标独立，不能把多角色输出当多份实验。
共识是待核查线索，不是事实判定；单方高严重度发现也要保留和求证。分歧写明各自条件、证据、最小区分实验与待决事项，不能只做投票或取平均。

## 项目必查项

按改动影响选择，不把清单扩大成全库审计：

- 导航仲裁与整机资源是不同范围；MTC 规划、Action 成功、实测停稳、抓持和物体账本分别证明。
- GraspNet 抓取候选、物体 6D 姿态、可见表面中心不可互换；质量分不等于成功概率，未碰撞检查的候选无执行权限。
- 地图/禁区“保存成功”与消费者使用同一版本后生效分开；暂停恢复不能重放旧租约或旧任务。
- 仿真运输的运动学附着不证明摩擦/夹持力/带载动力学；固定底盘操作不证明边走边操作。
- C++ 迁移同时保持取消、故障、数值边界和性能预算；均值改进不能抵消已约定的 P95/最大延迟退化。
- 相机完整帧配对、同 `/clock`、曝光同步、端到端新鲜度和标定是不同性质；GPU 利用率单点不能解释整栈瓶颈。

当前入口及场景选择见 [项目场景目录](../robot-scenario-boundary-validation/references/project-scenarios.md)，其中状态须按当次源码重新核对。

## 可选补充视角

只有问题需要时才启用：

| 视角 | 本项目检查 | 输出边界 |
|---|---|---|
| 产品/需求 | 操作员任务、可恢复性、误报警、失败后的保载/取回、维护成本、成功率分母 | 需求→能力→验收映射；不虚构商业收益或用户反馈 |
| 行业实践 | ROS2 Humble、Nav2、MoveIt/MTC、厂家接口、替代方案的适配成本与约束 | 核查官方文档/代码版本；“主流”不证明本机可行，不输出股票/产业报告 |
| 安全与适用标准 | 使用环境、人员接近、整机/机械臂/移动平台边界、危险源及残余风险 | 只做适用性与证据缺口梳理，不声称认证或法律结论 |

SSM/ISO 议题读取 [安全论证边界](references/safety-case.md)。不从公开摘要臆造条款或固定安全距离。

## 交付

使用 [评审记录模板](assets/review-record.md)，按影响填写而不是凑数：

- 结论：支持限定范围 / 补证后再决策 / 建议调整方案；明确针对设计、仿真或硬件哪一层。
- 每项 `F-id`：原文/源码锚点、关联 `C-id`、事实或假设、触发条件、影响、严重度、证据与置信程度、建议方向、关闭判据和 `SC-id`。
- 严重度与证据强度分开。尚未复现的高后果风险可以限制相关范围，但不能写成确定缺陷；证据不足不等于失败已证实。
- 若用户要求打分，先公开维度和锚点，缺证据为 N/A；不以总分抵消控制权、碰撞或停止确认等关键未闭合问题。
- 收集原始失败与反证。允许“未发现实质问题”，列清已查范围和未覆盖项。

将需验证的发现交给 [多场景与边界验证](../robot-scenario-boundary-validation/SKILL.md)，结果按 [证据分层](../robotics-validation-evidence/SKILL.md) 报告。
