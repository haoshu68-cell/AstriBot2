# 机器人运行时语言与迁移约定

- 后续运行时模块优先使用 **C++**，包括持续运行的 ROS 节点、控制与安全检查、几何和碰撞计算、感知处理、规划决策及执行逻辑。
- Python 主要用于启动、验证、数据采集与分析脚本。现有 Python 适配层逐步迁移；迁移期间可以保留薄绑定，避免在绑定中继续增加运行时算法。
- 按已定位的性能、可靠性问题和模块边界分步迁移，不为统一语言一次性重写整条链路。复用仓库已有 C++ 实现，先明确上下层的控制权和接口所有者。
- 每步迁移保持消息、几何版本、采集时刻、取消与故障语义兼容；保留原有安全预算。用边界用例、相同输入回放及隔离仿真验证行为和延迟，不能以放宽碰撞、时效或到位门槛换取验收通过。
- 交付时分别说明已实现、已验证和仍待验收的范围。涉及仿真启动、探查或清理时，同时遵守 [ros2-stack-ops](../ros2-stack-ops/SKILL.md)。
