# 多场景与边界条件验证设计

本技能决定“测什么、如何判定、覆盖到哪里”；[robotics-validation-evidence](../robotics-validation-evidence/SKILL.md) 负责证据记录与报告。
默认生成验证计划，计划完成不等于执行通过；执行只在本次授权与环境所有权范围内开展。

## 从主张生成场景

1. 把需求/不变量 `R-id`、主张 `C-id`、风险 `F-id/H-id` 映射到 `SC-id`。复用已存在的用例，不因增加场景数量重复同一命题。
2. 从 [项目场景目录](references/project-scenarios.md) 选受影响领域，并补正常、阈值、时序竞争、故障、恢复、负载/持续运行类别。N/A 写原因。
3. 先定义独立判据/观测量，再选择注入位置。被测模块自己的 success 不能作唯一 oracle；采用下游状态、物理反馈、独立真值或人工标注，并写局限。
4. 填写 [场景卡](assets/scenario-card.md)。最小字段包含基线、前置条件、精确刺激顺序、预期、禁止行为、测量、时限、样本量、资源所有权、清理与回退。缺关键字段标 BLOCKED，仍可推进不依赖它的其他场景。

## 边界覆盖规则

- 数值边界测试 `t−δ / t / t+δ`；说明单位、比较符、精度/舍入、δ 来源及有效配置。若未约定阈值或 P95 门槛，先标为候选/待确认，不能填一个“经验数”后宣称验收。
- 时间至少区分采集时间、接收时间、ROS 仿真时间、单调墙钟和 epoch。未来帧、重复时间、断流、回退、恢复逐一检查；重试不能刷新原请求期限。
- 状态切换覆盖“取消前/接受后/终态同时到达”“准备提交时版本变化”“节点重启后迟到结果”“部分消费者 ACK”；列事件偏序而非只测最终稳态。
- 接口边界含空/单条/满队列/溢出、NaN/Inf/非法单位/frame、乱序/重复、无 TF、配置更新、依赖超时与资源冲突；按实际输入域选择。
- 因果上相关的高后果组合单独测，例如载荷扩大＋costmap ACK 缺失、导航中相机断流＋GPU 满载、取消＋迟到成功。普通组合可用成对覆盖，不能把它当穷尽安全证明。
- 性能/迁移采用同输入对照、固定配置/模型/二进制、预热、重复、交错 A/B、固定分位数口径；同时核对输出、取消/失败语义、CPU/RSS、尾延迟。功能、性能、边界分别判定。
- 记录分辨率、采样和测量不确定度；到位/FOLLOW/REFINE、单帧/任务/场景分母分开，零样本不算通过。

## 判定维度

每条场景分开记录 `readiness=READY / BLOCKED / N_A` 与 `execution=NOT_RUN / PASS / FAIL / INVALID / N_A`。
缺参数时是 BLOCKED + NOT_RUN；局部可执行的轨迹拆子项，分别记录，不把整张卡自动判失败。执行后才判 PASS/FAIL；实验无效用 INVALID。另列：

- `functional_outcome`：任务成功、预期拒绝、非预期拒绝或未完成；
- `safety_invariant`：保持、违反或未知；
- `evidence_layer`：离线、隔离 ROS、隔离仿真、整栈仿真或真机；
- `performance_outcome`：预算内、超预算、未测或无判据。

预期拒绝 PASS 只证明对应防护，不能增加业务成功次数。注入器坏了、数据混源或非预期并发使归因失效时标 INVALID 并保留记录，不能算被测模块失败/成功。
仿真 RTF、ROS 时间与墙钟同时记录；其他任务的 GPU/仿真负载只观测不清理，归因受干扰就收窄结论或安排受控复测。

## 恢复与结束

对影响运动的故障，先抑制受影响的新命令并请求受控停止；记录底层终态、实测停稳/保载和持久化结果，按 [任务状态与事件契约](../robot-task-intake-execution/references/task-transitions.md) 检查重新准入的前置条件，不强制异步反馈按同一顺序到达。未确认停止、载荷状态或旧执行隔离时，不将冲突资源标为空闲；保留隔离或交给明确安全所有者。已确认的携物安全状态可以按新准入转交运输任务，不要求所有任务先松爪。纯只读故障验证不得凭空发停止命令。
恢复后再做正常用例，验证旧 epoch/旧许可/迟到结果不能复活任务，重试预算不被换 task_id 重置。

涉及启动/探查/故障注入先读 [ros2-stack-ops](../ros2-stack-ops/SKILL.md)；隔离包括 domain、Gazebo partition、端口、锁、build/install、日志与资源所有者，不能只改 ROS_DOMAIN_ID。离线能验证的语义无需启动共享栈。
真机只在用户任务包括该层且硬件准入已满足时执行；仿真范围的任务把硬件标 NOT_RUN/requires hardware，不自动扩大任务。

交付 `R → C/F/H → SC → E → 结论` 覆盖表：已运行/待运行/无效/不适用、未覆盖高风险组合、仍未知的判据及下一项最小验证。场景设计完成与机器人功能验收完成分开报告。
