## 场景族

| SC-id | 正常对照与边界/故障刺激 | 不变量和独立观测 | 最低适合的验证层 |
|---|---|---|---|
| SC-TASK | 正常提交；同幂等键不同负载；人工/路线/探索冲突；取消与迟到成功竞争 | 单一执行所有者；不重复执行；子 Action 终态、实际反馈、资源隔离分别观察 | 纯核心/隔离 ROS；停稳需要仿真/硬件 |
| SC-LEASE | 获得/续约/归还；期限 t±δ；丢续约 ACK；进程重启后旧命令重放 | 不重置原截止时间；新旧 owner/epoch 隔离；失联不重新授予运动 | 离线/隔离 ROS及保护链联调 |
| SC-NAV | 开阔路线；起终点航向受限；窄通道旋转/倒退；不可达目标 | 受完整足迹/扫掠约束；FOLLOW 与 REFINE、到位与漂移分开评分 | 几何回放→导航仿真 |
| SC-ENVELOPE | 空载/带载/偏载、home/非home；扩大包络时缺一个 ACK、旧 epoch、TTL 到期 | 未就绪不移动；保守几何贯穿控制器/两图/保护；实测姿态与版本一致 | 契约/隔离 ROS→携物仿真 |
| SC-TRANSPORT | 取物→收臂→导航→放置；空夹、一臂失败、RELEASE_PENDING 重启、退臂无解 | 保载、禁止盲目松爪/二次释放；场景与物体账本提交依赖实际确认 | 状态机/仿真；接触力和滑落另验 |
| SC-PERCEPTION | clear/far/near/tilted/yawed/occluded/close；对称模型、单平面、未知 CAD | 可观测性不足的拒绝不算功能成功；独立真值只供评分，不能泄漏到算法 | 固定真实输入回放→推理仿真 |
| SC-INFERENCE | 正常请求；NaN/Inf、空点云、错误 frame/标定/epoch、worker 退出、超时后结果迟到 | 无失效候选输出；有效候选仍需 IK/碰撞/准入；上下文绑定与取消可见 | 算法/真实 worker 隔离 ROS |
| SC-CAMERA | 完整 RGB/depth/info；到达乱序、重复、t±δ、断流、相机重启 | 按原采集/接收时间判龄；旧完整配对不续期；健康与有效几何分开 | 元数据回放→传输与渲染仿真 |
| SC-SYNC | 同组新鲜数据；帧先于边沿、边沿冲突、clock 回退、无锁定、曝光不一致 | 同 stamp 不推导硬触发；模拟证据带来源；缺物理计数/回读保持未验证 | C++/合成 ROS；物理同步另验 |
| SC-ZONE | 保存/生效/再载入；部分 ACK、错 map、消费者重启、边界点/自交几何、SLAM 回环 | 当前 context/token 且消费者已应用才准入；地图切换撤销旧许可；不自动退出禁区 | 几何/事务/协议→Nav2/RViz 仿真 |
| SC-RECOVERY | 局部卡住、轮滑/悬空/定位丢失的可用模拟；后方盲区、无进展、预算耗尽 | 恢复有时间/距离/次数预算；完整包络和后向观测不足就保持；人工接管 | 判定回放→受控仿真；真实硬件事件另验 |
| SC-ALARM | 重复故障、瞬时抖动、告警风暴、确认但物理故障仍在、进程重启 | 去重/升级/锁存按故障 episode；确认不自动解除故障或续跑 | 状态机/隔离 ROS |
| SC-LOAD | 多相机＋推理＋导航/操作；GPU/CPU/DDS/磁盘压力、队列满、长时运行 | 新鲜度、队列/内存有界、取消可响应；采集端到端延迟、RTF、丢帧、P95/最大值 | 固定工作负载对照→整栈仿真 |
| SC-MIGRATE | 同输入旧/新实现；整数/浮点边界、非法参数、取消竞争、8/64等实际负载档 | 消息、异常时机、状态转移、资源/性能预算分别对照；不凭编译或均值放行 | 差分/安装协议→闭环回归 |
| SC-SAFETY | 人员接近、遮挡、载荷/速度变化、检测和制动延迟、传感共因失效 | 风险论证与独立测量，不用 SSM 距离常量替代响应链或认证 | 设计分析/仿真；真实保护验证需硬件 |

组合至少考虑 SC-ENVELOPE×SC-ZONE、SC-CAMERA×SC-LOAD、SC-TASK×SC-TRANSPORT、SC-SYNC×SC-INFERENCE 中与本次变更相关者。不能以单场景全通过替代相关跨模块组合。

## 完整边界卡示例的填法

相机阈值若当前有效配置为 0.25 s，也必须检查实现使用的时钟、`<` 或 `<=`、整数纳秒或浮点转换。卡片写出这些来源，再测试 0.25 s 两侧及等值；只有“0.25”没有单位/时钟时，将数值判定标 BLOCKED。可先开展不依赖该值的重复帧/epoch 测试。

姿态目录中的 7 个场景来自已有记录，不预设全部应成功：先指定产品要求的可工作域，再分别报告要求域中的误拒绝、正确拒绝、有效输出精度与总体完成率。工况拒绝且机器人未动作，可以安全断言 PASS、业务目标 FAIL/未完成并存。

停止测试同时记录 t_cancel_requested、t_cancel_ack、t_action_terminal、t_measured_stopped；对应时钟、采样分辨率及不可观测缺口必须可查。观察不到停稳不能用进程退出替代。
