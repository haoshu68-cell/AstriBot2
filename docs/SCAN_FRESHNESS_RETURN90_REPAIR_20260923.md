## 修复切片与边界

先试单变量 C++ TF 接收/查询：独立私有 rclcpp context、节点和线程订阅相同 `/tf`、`/tf_static`，沿用100深度、reliable及静态transient-local、10 s缓存。原策略仍用同一扫描采集时刻、零等待查询；失败不能降级为 latest。原Python策略通过兼容接口取变换，不新增规划或控制发布者。

候选通过 `ASTRIBOT_POLICY_NATIVE_TF=1` 显式启用，默认保留原路径。线程关闭必须 cancel/join，仅关闭自有 context，不影响父Python ROS context。真实ROS时钟回退后，候选锁定为 `CLOCK_ROLLBACK_RESTART_REQUIRED`：精确时刻和显式latest查询都拒绝，`clear()`不能解除，须重建TF实例并重新准入；首次启用仿真时钟不触发该锁定。原因是普通TF消息没有纪元字段，单次清空不能识别随后迟到的旧纪元TF。已有Humble Python Buffer未自动清理回退缓存，候选在此边界有意更严格，不宣称自动恢复或行为完全等价。

保持原300 ms传感租约、原最后到达且TF可用选帧、原占据清空证据、碰撞、净空及六消费者ACK。暂不同时做snapshot优化，避免无法区分贡献。
