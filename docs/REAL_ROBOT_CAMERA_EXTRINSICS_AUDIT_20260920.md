## 矩阵检查

每路外参均为 4×4 齐次矩阵。平移项与生成的仿真 YAML 一致；旋转矩阵到 URDF
`mount_rpy` 的转换使用相机 optical 轴变换：

```text
camera_link -> camera_optical_frame =
[[ 0, 0, 1],
 [-1, 0, 0],
 [ 0,-1, 0]]
```

头部 RGB-D、左右双目旋转重投影误差约为 `1e-8`；躯干和腕部约为 `1e-3`，来源是
固件 JSON 中旋转矩阵保留小数位后不完全正交，并非平移或坐标轴映射错误。应继续保留
原始矩阵作为审计源，不要用四元数反向覆盖原始标定。

已执行一次 xacro 展开并逐关节比对六个 `${camera}_camera_joint`：

```text
六路 extrinsic_matrix_row_major 与 YAML 最大绝对误差：0
六路 URDF 平移与 JSON 平移误差：0--0.000003 mm
URDF mount_rpy 重建后的旋转误差：头部/双目约 1e-8，躯干/腕部约 1e-3
```

因此“JSON → 仿真 YAML → URDF mount”三者一致；`1e-3` 级差异来自源矩阵本身的
非正交小数截断，不是转换链路额外引入的误差。

左右腕畸变 `[1, 1, 1, 1, 1]` 按固件约定视为不可用哨兵，仿真中已转换为零畸变；腕部
外参仍然有效。
