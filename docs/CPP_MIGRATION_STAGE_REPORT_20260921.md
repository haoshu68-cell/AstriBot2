# 运行时 Python 向 C++ 迁移阶段汇报

日期：2026-09-21。范围：本线程负责的运行时迁移、去 pybind、验证与性能评估；不包含并行任务的地图、视觉及操作界面等全部工作。

## 一、阶段结论

已完成底层运动适配、几何状态、包络与最终保护、臂底盘耦合、导航任务仲裁及两项定位地图适配的 C++ 入口迁移，并建立了同输入差分、边界与故障测试、隔离 ROS 协议验证、性能对照及 Git 追溯记录。策略融合、健康检查、扫掠和风险计算已形成原生核心；策略观测节点已形成经过隔离验证的 C++ 候选，尚未完成完整策略业务链替换。

多个已测模块的处理延迟、CPU 消耗及常驻内存明显下降。当前成果属于源码迁移和离线／隔离 ROS 验证，尚不能报告全项目去 pybind 完成、整机闭环通过或真机部署完成。

按最新决定，迁移暂缓，保留时间戳扩域之前的版本：记录检查点 `a309d9bf`，其中策略整数／字符串修复实现为 `f4feccdf`。时间戳候选及实验另行归档；本次整理不恢复该候选，也不改动运行时代码。

## 四、代表性性能结果

各行使用对应阶段的同输入配对实验。指标定义、负载和采样窗口不同，只能在同一行比较 Python 与 C++，不能据此推导整机提速倍数。

| 模块／场景 | 指标 | Python | C++ | 变化 |
|---|---|---:|---:|---:|
| fixed_v2 包络提案 | 服务往返 P95 | 2.499 ms | 0.296 ms | 下降 88.1% |
| 几何状态：空载 | 采集到发布 P95 | 34.297 ms | 7.272 ms | 下降 78.8% |
| 几何状态：偏置载荷 | 采集到发布 P95 | 39.139 ms | 20.105 ms | 下降 48.6% |
| 臂底盘耦合 | 输出延迟 P95 | 0.715 ms | 0.357 ms | 下降 50.1% |
| 导航仲裁：假 Nav2 | 提交至终态 P95 | 24.886 ms | 6.245 ms | 下降 74.9% |
| 地图中继：1024² | 延迟 P50 | 65.959 ms | 1.973 ms | 下降 97.0% |
| 策略观测候选：8 目标 | tick 处理 P95 | 1.729 ms | 0.188 ms | 下降 89.2% |
| 策略观测候选：64 目标 | tick 处理 P95 | 3.963 ms | 0.573 ms | 下降 85.6% |

资源占用的代表性结果：

- 臂底盘耦合：CPU 中位数 5.40%→0.85%，RSS 65.90→24.11 MiB。
- 导航仲裁：CPU 5.28→0.40 ms/任务，RSS 64.12→26.62 MiB。
- 策略观测候选（64 目标）：整进程 CPU 14.15→1.95 ms/帧，RSS 63.95→28.87 MiB。
- 最终保护：legacy／fixed_v2 的测量窗口 CPU 时间分别下降约 93.8%／92.9%。

原始尾延迟和代价均有留存：耦合最大单条延迟 3.784→3.933 ms；小地图最大单条延迟 6.161→10.436 ms。几何完成通知优化还增加约 0.223 个百分点的单核 CPU 使用。因此不报告“所有场景、所有样本均更快”。短窗口 RSS 测量也不等于长期无泄漏验收。

策略表采用当前保留版本的字符串阶段数据，未混入已暂缓的时间戳候选。tick 计时不包含其前置视觉回调；整进程 CPU 则包含测量窗口内的 ROS 回调。

## 五、验证与可维护性交付

1. **同输入差分**：冻结原 Python 作为验证参考，比较消息字段、状态变化、错误、版本、期限和执行结果。
2. **边界与故障覆盖**：覆盖 NaN／Inf、float32 舍入、动态参数、TF 缺失／陈旧、时钟暂停／回退、过期消息、版本换代、取消和失效后的恢复；保留原始失败样本及修复后的结果。
3. **原生构建与安装检查**：对已迁移角色验证新安装中的唯一 C++ 入口、旧 Python 入口移除及 ELF 依赖；没有用关闭构建选项代替依赖链清零。
4. **性能证据**：保存交错运行顺序、原始样本、源码／二进制哈希和环境信息，便于对照和复现。
5. **参考实现清理**：累计 23 个历史模块仅用于验证、不随生产包安装；它们不是生产兼容入口。
6. **Git 追溯**：源码迁移、边界修复、实验和版本选择分开留档，没有重置共享工作区或覆盖共享安装。

已明确记录的兼容差异不作为“完全等价”隐藏：部分新非法参数拒绝规则比旧实现严格；12 项旧接口例外跳过不是通过；部分旧 Python 关闭过程存在重复 shutdown 异常。报告结论限定在实际检查的契约内。
