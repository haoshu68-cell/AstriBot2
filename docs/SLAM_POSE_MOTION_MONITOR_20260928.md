# 底盘监测统一使用 SLAM 位姿

用户 2026-09-28 明确要求：真机和仿真中的底盘运动、漂移、停止确认只监测 SLAM pose，取消 `/odom` pose/twist 对这些判断的参与；抖动必须正反抵消，禁止绝对误差积分。

## 数据流与计算

`voxelslam → /slam/pose (PoseWithCovarianceStamped, map 下底盘位姿) → 搬运/脱困/停止确认/验证脚本`。

SLAM 发布入口为 `astribot_s1_slam/src/highrate_odom.hpp::publish_anchor_pose`，经过 `imu_pose_to_chassis` 转换。它是激光校正的位姿；不把 Gazebo 真值、轮里程计或高频外推 TF 当作同一监测源。已有导航控制需要的里程计输入继续承担控制职责。

相邻样本增量为 `dx=x[i]-x[i-1]`、`dy=y[i]-y[i-1]`、`dtheta=remainder(theta[i]-theta[i-1], 2*pi)`。分别累计有符号增量后，检查净位移与净转角；位置直接相减 `pose[i]-pose[anchor]` 与有符号增量求和等价，不重复积分相对锚点误差。

小幅往返抖动不会因观测次数增长而产生虚假的累计漂移。仍检查窗口内各样本的净偏差；已越界的大幅移动不能因为后来返回原位被记为全程静止。窗口与门槛按各模块现有职责保留，不增加滤波器或调整保持控制器。

只接受递增的源采样戳，旧帧/重复帧不覆盖最新位姿；不拿观测年龄或未来采样戳与本地 ROS 时钟比较后报过期。无样本不能凭默认零值或其他来源声明停止，重复播放同一帧也不能生成停稳时长。

## 本次范围

- 搬运执行器、MTC 执行监测、导航交接：直接消费 SLAM pose。非导航净位移门槛保持 0.02 m，净旋转保持 0.02 rad；已批准的仿真放宽旋转配置仍为 0.05 rad。
- 停稳确认：SLAM 样本接收跨度至少 0.6 s，窗口净平移不超过 0.005 m、净转角不超过 0.01 rad；保留动作终态、实际零命令及资源身份检查。移除轮里程计采样率假设和 twist 阈值。
- 导航侧起始、转角、脱困和终端停止监测：切换监测来源；搜索、MPPI、控制误差算法和碰撞门槛不变。
- 主线客户端及当前录制配置同步切换 `/slam/pose`。历史运行证据保持原样，不将 front65 的旧失败重新标为通过。
- `idle_position_hold=true`、`idle_position_kp=3.0` 不变。

## front66 集成结果：坐标原点混用，主线未通过

新部署的 89 项产物哈希、12 个包解析以及 32 项 ELF 依赖检查通过。front66 已走完 PICK 并进入 NAVIGATE；脱困规划选择 BACKWARD 0.10 m，但第一次控制回调立即抛出 `DEPARTURE_DRIFT`，未进入 PLACE。资源释放确认，清理停稳窗口 0.636 s，净位移 0.000320 m、净转角 0.000348 rad，零命令确认；Gazebo/RViz 保留。

此次主线原有 `slam_backend=static_map` 使用仿真地图坐标，`map_provider` 发布恒等 `map→odom`，规划起点为 `(0.247299341, 0.146521739, 1.580225525)`。并行 Voxel-SLAM 在无 previous_map 时从自身初始坐标起步，`/slam/pose` 接近 `(0,0,0)`，却同样标注 `map`。此前只验证 frame 名称而未验证原点注册是本次集成遗漏。

`DepartureController` 直接把该 SLAM 位姿减去规划起点，横向偏差超过 0.03 m 或航向误差超过 0.03 rad 即抛出 `DEPARTURE_DRIFT`；错误锁存，后续控制周期重复抛出同一错误，最终 Nav2 控制耐心耗尽。没有将每次误差绝对值积分，也没有在此重新运行环境碰撞检查。此次报错不构成机器人实际脱困偏离证据。

剩余最小工作：在现有 SLAM/地图注册入口统一真实坐标语义，同时核验到位比较的同一依赖；不在各消费者硬编码出生点或通过当前 Nav2 pose 临时对齐来替代 SLAM 观测。此修复尚未实施/验收，不调整碰撞门槛或偏差阈值。

`front66_summary.json` 保存主线结果。外部场景目录 `front_transfer_scene66_world40_20260928` 的录制已封口：视频 112.1 s、1280×720、1121 帧，全片解码通过；bag 含 1729 条 `/slam/pose` 和 5141 条执行器状态。视频及 bag 仅证明本轮抓取至脱困失败的过程，不能作为完整搬运放置验收。
