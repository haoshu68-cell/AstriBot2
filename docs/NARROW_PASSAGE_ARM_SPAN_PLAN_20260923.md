本方案只衔接当前任务的窄通道规划、实际臂展和对应验证，不重排整个 I 任务链。
通行依据是当前双臂、身体和附着物的几何及其运动扫掠，不能由底盘宽度或姿态名称代替。

## 3. 实际几何到运动执行的数据流

1. URDF 碰撞形状与实际关节状态经 FK 得到身体、左右臂和末端的当前位置。
2. 经确认的附着物提供挂载 link、形状和局部位姿；EMPTY 也使用现有账本与场景读回证据。
3. RobotModel 合并全身与附着物投影形成 physical footprint，并计算高度及高度分层信息。
4. 关节保持误差界和既有几何 padding 形成 reserved footprint，保留非对称和前后伸出。
5. FixedEnvelopeCore 固定本次 reserved footprint，加既有 clearance 形成 installed footprint。
6. 实际安装的 installed footprint 进入 global/local costmap；现有消费者确认与包络身份保持一致。
7. ExactGoalPlanner 检查整个多边形的平移和旋转连续扫掠；中心路径只负责搜索或路线意图。
8. FixedCorridorPolicy 使用 reserved 多边形及既有 clearance/通道余量，计算偏移、进出状态和航向约束。
9. ArrivalController 使用实际安装多边形检查命令扫掠。当前候选已移除末级 final protection 速度输出，包络有效性在任务入口、BT 与控制器的既有职责内处理；navigation_constraint 只提供上游约束与诊断，候选运行接线仍待闭环确认。
10. 途中关节、附着物或几何版本变化由已有固定包络链处理，不能靠重发旧尺寸继续通行。

高度投影与有效覆盖沿用现有 geometry_state 合同；二维 footprint 不能单独证明上方障碍可见。
保留原几何时刻、对象、版本和碰撞语义；不删除对象、不换旧快照时间戳、不放宽原时效。

## 4. 左右不对称的可行偏移

令通道宽度为 W，沿通道为 s，左侧为正横向 d；θ 是机器人相对通道的航向。
按当前策略将 reserved 多边形旋转 θ，得到横向支持边界 y_min(θ)、y_max(θ)。
令 m 为现有 clearance、payload_extra、boundary、tracking 四项之和；改用 installed 时不能重复叠加其中已含的余量。
允许的中心横向区间为：`-W/2 + m - y_min(θ) ≤ d ≤ W/2 - m - y_max(θ)`。
区间为空即该姿态不可通行；可行区间中心为 `d* = -(y_min(θ) + y_max(θ))/2`。
例如左右边界为 -0.20 m、+0.44 m 时，几何中心偏移为 -0.12 m；这不是任意门宽可过的承诺。
直通检查实际行进航向；拐点必须检查整个旋转范围，不能只比较两个端点姿态。
已有地图和预测占据检查包含航向容许范围的保守扩张，不能把当前角度区间单独解释为全部安全证明。

## 5. 入口姿态调整与完整退出

需要收臂时，在全身仍位于入口外、调整扫掠可行的位置停稳，执行现有姿态调整与携物保持流程。
收臂不是底盘临门后临时旋转关节；应在接近路线确定前确认所选姿态及附着物能覆盖整段路线。
调整完成后以实际关节和附着物重新确认固定包络，再按该几何规划；不能仅设置姿态标签。
没有可行姿态时明确报告不可通行或选择已有绕行方式，不把无期限等待作为自动收臂功能。
令 x_min(θ)、x_max(θ) 为纵向支持边界，入口位于 s=0、出口位于 s=L。
入口外条件使用 `s + x_max(θ) + m < 0`；完整退出使用 `s + x_min(θ) > L + m`。
中心越过入口或出口不代表长臂和携物已经越过；允许转弯的位置由完整几何与实际扫掠决定。
途中需要换姿态时，沿用停止、解除原固定运输状态、调整、重新确认包络和重规划的现有职责。

## 6. 已确认的出口计划与执行冲突

原 route_fits 仅裁剪中心位于 `[0,L]` 的路径段，而通道退出判断已要求后缘完整退出。
离线复现：后伸 1 m 的多边形、3 m 长通道，路径 `(-1.5,0)→(3.1,0)→(3.1,1)`。
原检查返回 route_fits=True；中心到出口外且航向为 0 时为 TRANSIT，转到 0.2 rad 后被通道限转拒绝。
这证明计划与执行不一致，不能据此声称实际发生碰撞：全身规划扫掠和控制器仍有碰撞检查。
当前修复使用 C++ 拐点连续旋转检查，保留原 Python 适配：枚举多边形与通道边界的顶点—边接触角，再调用既有完整多边形距离核。外接矩形相交不再直接判失败，避免误拒绝通道外斜角转弯。
确定违反当前通道转向约束的路线立即返回 `CORRIDOR_ROUTE_TURN_UNREACHABLE`，不消耗等待预算，也不擅自移动目标点。
当前 19 项 C++ 检查、16 项策略回归通过，另有 1000 组采样交叉核对；窄通道完整实际臂展/携物闭环仍待专项验证。
关闭条件是相同反例提前得到一致的路线结果，合法完整退出后转弯仍通过，且实场不再因此停滞。
