# RViz 集成工作站界面汇报（演示样例）

日期：2026-09-24。优先打开 `汇报.html`：图片已内嵌，可单独复制该文件、离线打开，点击页签切换 6 张原始截图，也可打印。`images/` 是未经界面美化替换的原始窗口截图，可直接插入汇报材料。

## 建议讲解顺序

1. **日志与回放**：记录开始/停止、人工故障标记、关键参数快照与只读回放入口集中在 RViz 工作站内。右侧同时显示仓库存图与合成样例路径。
   本次边界：当前未连接记录后端，采集按钮置灰；“打开只读 3D / 参数回放”可用。回放控制器目前仍为独立窗口，不能称为完整内嵌回放。

2. **导航与路线**：提供路线点表格、顺序调整、保存/加载、开始导航和取消入口，保留右侧地图视图。
   本次边界：本图未下发导航任务。右侧路径由离线演示包提供，不是左侧空路线表已执行的结果。

3. **探索建图**：界面包含默认仿真启动入口、探索暂停/恢复、结束探索并保存部分地图、地图保存重试。
   本次边界：本次没有点击启动仿真，也没有执行探索或存图；长说明文本仍可见横向截断，尚未在本轮修改。

4. **地图与工位**：同屏提供地图版本、工位版本、导入目录、楼层、工位用途和停靠/作业坐标。
   本次边界：地图管理后端未接入，目录为空、修改和切换受限。右侧是回放包地图，不是本页已加载成功的业务地图。

5. **业务场景**：展示业务场景选择、场景 ID/名称、地图版本绑定和设备列表入口，统一使用同一 RViz 工作站。
   本次边界：当前默认类型为 echo；场景服务未连接，没有伪造设备、已保存场景或加载成功状态。

6. **虚拟墙与禁区**：界面提供形状、名称、墙宽、额外边距和绘制/完成/撤回入口，说明约束归属地图版本。
   本次边界：本次未提交禁区，图中不展示虚拟墙生效结果。导航/探索约束是否生效仍需消费者确认和业务验证。

## 可直接使用的汇报表述

当前已将业务场景、虚拟墙禁区、导航路线、探索建图、地图工位、机械臂预览及日志回放入口集中到 RViz 工作站。截图展示的是实际运行的 C++ 插件和同屏地图区域，其中日志与回放页提供统一记录、故障标记、参数快照及只读回放入口。本次采用离线演示包，在线控制后端未连接；专用回放控制与参数窗口仍独立，业务闭环和既有时间同步缺陷不在本次截图验收范围内。
