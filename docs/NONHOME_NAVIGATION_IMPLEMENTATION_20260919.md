## 几何与状态契约

新增 `astribot_s1_robot_geometry` 提供 Python 模型/多边形库、只读 ROS 几何生产者和 C++ 填充多边形格网检查器。支持 URDF box/sphere/cylinder，mesh 使用保守 AABB；附着物首版支持 link 坐标系下的 box/sphere/cylinder，未知形状或 frame 明确拒绝。

球/圆柱通过支持函数生成外接多边形；误差外扩使用外接圆盘近似。对 ROS Point32 的舍入另加极小外扩并重建凸包，避免传输后出现内缩或近共线凹点。高度分层是保守投影，不是精确三维碰撞证明。

22 个会影响几何的必要关节来自本机 URDF。每关节分别保留源时间，缺失不补零；默认最大年龄 300 ms，跨关节偏差 100 ms。轮子只在“叶节点、碰撞体与关节轴同心且旋转对称”被几何证明时排除保持要求，不使用名称白名单；在这类节点添加非对称附件会被拒绝，须更新模型。

`RobotGeometryState` 区分采样时间、发布时间和源数据决定的 `valid_until`。模型、附着物、源实例或时钟 epoch 变化撤销旧承诺。几何生产者读取 PlanningScene 的实测附着状态，不把视觉发现当作已经抓牢。

`NavigationEnvelopeV2` 保留原 `RobotEnvelope` 的 ABI，并新增独立协议：

- `reserved_footprint`：模型和关节保持误差的外包；保留左右/前后不对称。
- `installed_footprint`：预留多边形加环境余量；8 cm 每侧仍保留，Nav2 额外 padding 设为 0。
- 会话、epoch、模型/载荷版本、来源序号、保持 token、限值及失效时间。
- epoch 只随新承诺变化，采样序号随新观测变化。重复心跳不能续期已过期的测量。

## 包络安装与控制权

`SetFixedEnvelope` 只引用协调器缓存中有效的 GeometryState 序号，不接受调用者任意提交一个小多边形。请求必须停车且里程计有效，限值只能收紧，附着物存在时要求明确正载荷质量。新包络保留至少原底盘基准尺寸。

任务在完成机械臂动作后发布 `ArmHoldStatus`。除了实测姿态留在误差界内，还须从 controller_manager 确认必要关节的 position 接口由 active 的 JointTrajectoryController 占有；该证据有单独有效期。现有任务资源租约仍负责协作调用者互斥；这不是对绕过任务接口的任意外部 ROS 发布者的访问控制。硬件驱动的保持/制动证明尚待开机验证。

确认来源为全局地图、局部地图、planner、controller、policy、protection 六个消费者。原生插件直接回读对应 costmap 当前多边形并确认完整顶点；Python 消费者在实际应用几何后确认。会话/epoch/hash 不符、数据过期、关节超界或附着物变化均停止放行。初始 HOLD、正常换包络和取消保持使用同一 epoch。

V2 模式下旧 ready 请求被拒绝；旧接口仍可撤销导航。向旧协议发布的状态始终为 HOLD，不能在新组件缺失时降级成底盘矩形继续行驶。修改机械臂前先撤销保持 token；VLA/MTC 仍走原技能和执行边界。

## 碰撞和通道规则

Python 风险/停止扫掠与 C++ 路径/最终指令检查均采用完整凸多边形。检查包括落在多边形内部的障碍，不仅描边。离散路径段/指令采样额外覆盖样本间最大位移；未知栅格和地图外按不可通行处理。MPPI 保持 Omni 和既有 footprint critics，新增检查是路径与最终执行的独立复核；不声称 Humble 存在一个通用 EXACT 开关。

| 场景 | 决策 |
|---|---|
| 开阔区域，姿态和版本有效 | 沿原安全路径执行；速度受当前包络限值约束 |
| 窄通道已对正，当前姿态及路径/预测扫掠均安全 | 直接低速通过；不因宽度档位强制停车，也不依赖 home 标签 |
| 左右不对称但总宽可通行 | 分别计算两侧间隙，提供 `(右侧伸出量-左侧伸出量)/2` 的偏置目标；路径仍须通过完整扫掠 |
| 入口需要对正或移位 | 在身体完全位于通道外时停车；只在相应扫掠已验证后执行 |
| 通道内部航向不符合准入范围 | 不原地转向；报告 `ROTATION_FORBIDDEN_IN_NARROW_PASSAGE` |
| 通道内终点要求原地改变航向 | REFINE 报告 `GOAL_HEADING_UNREACHABLE`；原地位置目标也保留通道规则 |
| 固定姿态横向投影过宽 | 停在入口外改姿态或绕行；不自动收臂，不缩小足迹 |
| 倒车/退出 | 仍需现有独立 reverse-exit 扫掠证明；普通通道许可不自动授权倒车 |
| 漂移、关节/载荷/保持/版本证据失效 | 撤销准入；保留上次包络，不自动恢复为底盘尺寸 |

`PassageAssessment` 输出两侧余量、允许横向区间的目标、航向范围、决策原因及绑定的包络版本。地图边界误差和跟踪误差继续单独记账。本次没有为了让 85 cm 通过而任意降低现有地图误差预算。离线 85 cm 用例为 0.64 m 预留宽度 + 2×(0.08+0.01+0.01) = 0.84 m；这不是该机器人任意姿态或现有自动测宽配置的闭环能力证明。

## 感知与规划器候选

新模式通过标准感知入口把 overhead 切片上限从 1.55 m 提高至 2.2 m，并由几何生产者回读实际参数；源配置不可用或整机上界超过该过滤范围时不放行。过滤上限不等于传感器真实可见范围；雷达/相机视场、遮挡、低障碍、上游点云裁剪仍须闭环场景验证。未直接叠加 VoxelLayer，以免假设一层三维缓存就提供了三维整机碰撞。

两张 costmap 在 fixed_v2 关闭基于整机凸包的 footprint interior clearing，避免清除两臂之间或臂下真实障碍。当前逐 link 自过滤继续使用原实现。续作新增逐附着实体自过滤：几何生产者发布经 PlanningScene 确认的完整附着快照，点云投影节点用采集时刻 TF 检查 box/sphere/cylinder 内部，成功处理实际点云帧后回传版本。任务等待对应版本确认再移动载荷，版本或时效失效时几何不放行。仅仿真启用，按当前激光 1 cm 距离分辨率使用每实体 6 mm 数值/量化余量；不清空整个整机凸包。

`ExactGoalPlanner` 保留原默认，新增 `ExactHybridPlanner`、`ExactLatticePlanner` 供评估。实验插件需要 `planner_evaluation_only=true` 才能配置，不默认参与交付任务。现装 Omni lattice 示例只有 16 个非均匀航向，不能冒充 Hybrid 的 72 bins。72 bins 对 1 m 外伸点的半格航向位移约 4.36 cm；是否加密须由误差预算和计算时间实测决定。保留 `downsample_costmap=false`，不将 TEB 加为未经验证的自动后备。

目前只验证了三插件可加载，没有实际比较路径成功率、朝向保持、倒车拐点和到位精度。需要补齐执行链对 SE(2) 轨迹朝向的语义后才能择优切换。
