## 已实现内容

1. 轨迹几何复核改为本机 JTC 的真实线性、三次或五次插值，保留原轨迹、时间、终点和任务阶段。用 Bernstein 控制点包围整个关节曲线区间，避免仅看端点或中点漏掉往返、超调。
2. 增加固定场景中的离线连续区间检查：对完整机器人、另一臂、附着负载、旋转/平移关节及 mimic 关节计算运动范围，结合 FCL 全机器人距离查询，返回 CLEAR/RISK/UNKNOWN。状态数或计算时间预算不足返回 UNKNOWN。它目前只用于离线/影子验证，尚未接到在线运动放行。
3. 在原 JTC 上增加 C++ 执行租约；控制周期完成后才确认新租约并接受目标；执行器失联或显式撤销后终止旧 Goal 并切换到 JTC 的当前位置保持。过期租约不能被迟到正向消息复活。保留一个 FJT 入口，删除直接轨迹 topic 命令入口。
4. 原生执行器等待全部六个控制器确认租约，再发送原有轨迹；控制器配置及准入仅接受新插件类型。撤销先于持久化操作发送。没有标准 JTC 类型的兼容放行分支。
5. 执行保护增加关节/SLAM 消息断流与重复源时间戳检查；执行器检查保护状态的心跳期限，并锁存执行期间收到的负向状态，后续排队的正常消息不能覆盖撤销。
6. 补齐原 MTC 包缺失的保护头文件安装规则，更新相关 Python 验证夹具。新增功能实现为 C++；Python 改动均为测试/性能测量。
7. 在实际点云集成回调中增加 C++ `ObservedPointCloudUpdater`：同一地图写锁内记录来源、实际使用的变换、不可变地图快照和版本；单独记录本帧射线经过且当前为空闲的体素。自体过滤清除不计作空闲观测。独立分支的两路传感器配置仅使用新更新器，原更新器仅在对照测试中实例化。详见 [接口边界](../ws_robot/src/astribot_s1_manipulation/OBSERVED_OCTOMAP.md)。

执行租约的 300 ms 是当前候选参数，**不等于物理停车时间**。控制器层的保持动作沿用 JTC 行为。已测空载左腕小幅运动的取消、心跳中断、撤销、执行进程 SIGKILL；全臂/负载制动距离、加速度/冲击和持物稳定性仍未验收。

## 固定场景区间检查的依据与边界

对每个轨迹段用端点位置/速度/加速度建立与实际 JTC 插值对应的 Bernstein 曲线。递归分割保留整个子区间的关节范围。对碰撞体沿父关节链累积：旋转关节使用“到关节轴的保守半径 × 角度变化上界”，平移关节使用平移变化上界；半径包含碰撞体局部范围、连杆固定偏移和可能的平移伸长。附着物按其真实附着变换参与计算。

若所有碰撞点最大位移界为 B，则区间世界净空下界为端点净空减 B，自碰撞净空下界为端点净空减 2B。无法证明满足要求时继续分割；检查到风险或预算不足时明确退出。沿用原 ACM，不修改障碍、负载或允许碰撞配置。

该结论限于给定的固定场景、几何模型和显式轨迹段，不包含未观测区域、动态障碍运动、场景来源有效性、当前实测状态到首点的过渡、跟踪偏差及停止可达范围。计算时间是协作式预算；单次 FCL 调用不能被强制抢占，超时结果不会标为 CLEAR。当前未声称已完成 P1 在线影子监测或动态避障验收。

## 自有 Gazebo 停止量测

原外部会话结束后取得独占仿真锁，使用固定六摄像头、真实 VoxelSLAM、底盘位置保持和全部六个新控制器。`session01` 只读发现相机原点错误并关闭；修复后新建 `session02`（domain94），MoveGroup 的运动执行实际读回为关闭，原生任务执行器没有启动。验证脚本是本实验唯一运动提交者，未替换生产任务入口。

空载左腕 joint7 使用 ±0.2 rad/4 s 三次轨迹，实际位移达到 0.025 rad 后触发停止。四类各 30 次交错重复，**120/120 符合本次功能判据**。每次都记录旧 Goal、保持指令及新鲜关节/SLAM 的至少 0.6 s 稳定窗口；并不代表动态障碍、全臂、负载或自动重规划通过。

| 停止原因 | 触发至观察到保持命令，中位数 / 最大值 | 触发后采样最大关节位移 | 触发至停稳确认，最大值 |
|---|---:|---:|---:|
| Action 取消 | 20.0 / 37.2 ms | 0.000475 rad | 815.4 ms |
| 停发心跳 | 284.8 / 326.6 ms | 0.017331 rad | 989.4 ms |

停稳确认包含 0.6 s 观察窗口，不能当作纯制动时间；保持命令通过控制器状态消息观测，含传输/采样延迟。SIGKILL 的发送 Goal 和心跳进程确实退出为 -9，另一个只读进程确认同一 UUID 的 ABORTED 及实测停稳。

**尾延迟仍需处理**：`23_process_loss.json` 从最后一次心跳到观察到保持为 **381.758 ms**；目前没有隔离控制更新、仿真停顿和观测传输各自贡献，禁止将 300 ms 租约直接当作整机停止上限。单独采集的一段世界统计窗口 RTF 中位数 0.9996、最小 0.2712；它不是每轮或全程 RTF。当前只记录时延分布，未批准全臂制动预算。

收尾前独立只读检查通过：已观察 Goal 均终态、执行心跳发布者为 0、关节与 map 下 `/slam/pose` 停稳。自有进程随后退出，`remaining_owned_pids=[]`、`log_capture_errors=[]`，独占锁实测已释放。**续做时复核原日志发现 MoveGroup 子进程退出码为 -11，先前以 launch 返回 0 写成“正常退出”有误；更正见本文顶部及退出崩溃对照。** 已经通知申请资源的主线窗口，不再占用 Gazebo/GPU。
