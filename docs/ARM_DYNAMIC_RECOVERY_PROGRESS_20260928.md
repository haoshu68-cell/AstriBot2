# 机械臂动态避障分支实施记录

合入目标由用户确认为 `chassis-effort-drive`。工作目录为 `/home/yjh/WorkSpace/astribot_arm_dynamic_recovery`，分支为 `codex/arm-dynamic-recovery`。**整体功能未完成验收，未合并、未推送，也未替换正在运行的整机部署。**

## 已实现内容

1. 轨迹几何复核改为本机 JTC 的真实线性、三次或五次插值，保留原轨迹、时间、终点和任务阶段。用 Bernstein 控制点包围整个关节曲线区间，避免仅看端点或中点漏掉往返、超调。
2. 增加固定场景中的离线连续区间检查：对完整机器人、另一臂、附着负载、旋转/平移关节及 mimic 关节计算运动范围，结合 FCL 全机器人距离查询，返回 CLEAR/RISK/UNKNOWN。状态数或计算时间预算不足返回 UNKNOWN。它目前只用于离线/影子验证，尚未接到在线运动放行。
3. 在原 JTC 上增加 C++ 执行租约；控制周期完成后才确认新租约并接受目标；执行器失联或显式撤销后终止旧 Goal 并切换到 JTC 的当前位置保持。过期租约不能被迟到正向消息复活。保留一个 FJT 入口，删除直接轨迹 topic 命令入口。
4. 原生执行器等待全部六个控制器确认租约，再发送原有轨迹；控制器配置及准入仅接受新插件类型。撤销先于持久化操作发送。没有标准 JTC 类型的兼容放行分支。
5. 执行保护增加关节/SLAM 消息断流与重复源时间戳检查；执行器检查保护状态的心跳期限，并锁存执行期间收到的负向状态，后续排队的正常消息不能覆盖撤销。
6. 补齐原 MTC 包缺失的保护头文件安装规则，更新相关 Python 验证夹具。新增功能实现为 C++；Python 改动均为测试/性能测量。

执行租约的 300 ms 是当前候选参数，**不等于实测物理停车时间**。控制器层的保持动作沿用 JTC 行为；制动距离、加速度/冲击和持物稳定性仍未验收。

## 固定场景区间检查的依据与边界

对每个轨迹段用端点位置/速度/加速度建立与实际 JTC 插值对应的 Bernstein 曲线。递归分割保留整个子区间的关节范围。对碰撞体沿父关节链累积：旋转关节使用“到关节轴的保守半径 × 角度变化上界”，平移关节使用平移变化上界；半径包含碰撞体局部范围、连杆固定偏移和可能的平移伸长。附着物按其真实附着变换参与计算。

若所有碰撞点最大位移界为 B，则区间世界净空下界为端点净空减 B，自碰撞净空下界为端点净空减 2B。无法证明满足要求时继续分割；检查到风险或预算不足时明确退出。沿用原 ACM，不修改障碍、负载或允许碰撞配置。

该结论限于给定的固定场景、几何模型和显式轨迹段，不包含未观测区域、动态障碍运动、场景来源有效性、当前实测状态到首点的过渡、跟踪偏差及停止可达范围。计算时间是协作式预算；单次 FCL 调用不能被强制抢占，超时结果不会标为 CLEAR。当前未声称已完成 P1 在线影子监测或动态避障验收。

## 验证与性能证据

证据目录：[arm_dynamic_recovery_20260928](evidence/arm_dynamic_recovery_20260928)。原始失败与无效尝试一并保存，见 [invalid_attempts.md](evidence/arm_dynamic_recovery_20260928/invalid_attempts.md)。

- 14 项真实插值和区间检查测试包含薄障碍落在安全采样点之间、三次/五次超调、相同端点往返、关节越界、奇数纳秒、另一臂、附着物、旋转偏移和 mimic。另以 100 个固定种子、独立 Hermite 多项式稠密比较极值，并验证输入轨迹没有改变。
- 13 项控制器插件/动态加载测试使用实际 JTC 生命周期、Action 和 update 实现，但状态接口为理想位置接口；覆盖正常终点、断联、撤销、重复/迟到心跳和过期锁存。
- 隔离 ROS 协议覆盖正常执行、缺控制器确认、显式撤销、保护节点断流、负向消息后排队正向消息、错误上下文、迟到 Goal 接受与取消、未知结果隔离及重启后不重放。
- PICK/PLACE 全部阶段的隔离协议测试均通过，各自 30 个控制器目标、一次物理事务；完成 HOLD 后按原协议取消并释放资源。夹具与真实 MoveIt 的附着操作、剩余阶段响应保持一致；不代表 Gazebo 或真实抓放通过。
- 4 项故障/并发情景各重复 25 轮，100/100 通过；未进行两小时整机稳定性验收。
- 分组回归累计 233 个用例，221 个通过，仍有 12 个既有失败：ArmHold 5 个、ResourceAuthority 1 个、PayloadCommand 3 个、PayloadFrames 3 个。已从未修改的 `2775a3d4` 归档重新构建，确认同样的失败；新的 latest-time 契约测试通过。**这不是全套通过，未删除断言或恢复旧时间语义来制造通过。**

30 轮 A/B 交错控制器微基准，100 Hz 理想位置接口，同一单关节轨迹；各轮均值的中位数如下：

| 指标 | 原 JTC | 增加执行租约后 | 观测差值 |
|---|---:|---:|---:|
| update 函数 | 18.774 µs | 17.204 µs | -1.571 µs，不能据此声称加速 |
| 心跳收发/回调及 update | 110.289 µs | 131.198 µs | +20.908 µs，+18.96% |

原始数据及二进制哈希见 [controller_benchmark_final/summary.json](evidence/arm_dynamic_recovery_20260928/controller_benchmark_final/summary.json)。这是共享主机上的单控制器局部测量，含合成的 100 Hz 心跳；生产执行器目前为 20 Hz 心跳。不能外推为六控制器 CPU、Gazebo 整机或真机性能，也不能替代长时稳定性试验。

## 尚未完成的必要工作

1. **场景证据绑定**：在实际点云集成路径建立原子的来源、观测时间、地图版本和观测覆盖证据。现有 PlanningScene/filtered cloud 时间戳不足以证明这一点；禁止据此直接发布在线 CLEAR。
2. **实际执行绑定与反应预算**：将最终发送轨迹、Goal、执行代次、控制器实测进度和反馈绑定到检查结果；实测关节和 SLAM 更新、旧 Goal 终态及停止窗口共同证明停稳。
3. **Gazebo 停止实验**：冻结实际模型、控制器参数和速度/负载范围，测量风险到命令改变、再到实测停稳的时延和位移，以及进程崩溃、负载保持和队列延迟。当前其他任务仍占用整机仿真资源，已询问可用独占验收时段；未停止其进程。
4. **有界自动恢复**：上述门槛通过后，在左臂空载自由空间阶段从实测停止点重规划到原批准终点；保持原期限、次数、后缀约束与物理副作用。受约束接近/抬升/退出不能改为任意绕行，抓放/附着事件不能重放。
5. 按原方案完成动态障碍、遮挡/过期、结构变更、重规划失败、取消竞争、负载、右臂/双臂的对应验收；完成整机 A/B 与长时稳定性验证、消除主线回归分歧后，再合入 `chassis-effort-drive`。

当前可执行的下一步是 P0 仿真量测和 P1 场景来源/在线绑定；不能将已完成的离线核心与失联保护统称为已经完成动态避障或自动恢复。
