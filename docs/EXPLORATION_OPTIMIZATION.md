# 自主探索优化实施记录

本轮在 `astribot_autonomy_core` 与 `astribot_s1_exploration` 落地探索正确性和选点质量优化。保持现有架构边界：探索只提交 NavigateToPose 任务；候选规划仅供比较和校验，不直接执行返回路径，不增加速度发布者。本文记录代码与离线证据，不代表真机或标准符合性认证。

## 1. 正确性与进度语义

- 相同几何、相同栅格内容的地图消息保留不可变快照，不因消息对象变化作废正在计算的结果。内容比较仍为 O(N)，未宣称免除地图拷贝成本。
- 搜索结果使用任务代次、取消标志、几何一致性、墙钟年龄和机器人位移共同筛选。同几何的新内容允许复用候选，但重新检查其是否仍为前沿，随后仍须通过最新校验图上的目标与路径检查。旧结果不能为新地图证明“没有前沿”。
- 分开统计膨胀前原始前沿、膨胀后合格前沿、可达前沿和未知格。搜索异常不表示完成。
- 只有当前地图无前沿且无未知格，连续满足确认次数与稳定时间后，才报告 `CURRENT_MAP_COMPLETE`；范围明确为 `completion_scope=current_map`。地图内容改变后协调器退出完成态重新评估。
- `UNREACHABLE_FRONTIERS` 表示有前沿但当前不可达；`UNOBSERVABLE_UNKNOWN` 表示尚有未知格但无观测前沿。两者均不是完成。实际 SLAM 地图常含边缘未知格，因此这一判定保守；如需“指定区域探索完成”，后续须增加明确的 ROI/覆盖率契约，不能直接忽略未知格。
- 独立候选建议节点也使用完成迟滞，并在地图过期、变化或搜索失败时停止输出新目标、撤销完成结论。

## 2. 选点质量

- 每轮优先保留来自不同前沿簇的候选，再补足候选数量，避免规划预算被同一簇占满。
- 在候选规划预算内比较多条通过验证的路径，以实际路径长度替换直线距离项，并加入累计绝对转向角代价。总评分为距离权重乘路径长度，加访问惩罚项，减观测收益项，再加转向权重乘累计转向角。
- 预算到期或候选比较完毕后，从已通过验证的结果中选最优者；下发前再次检查当前前沿、最新校验图的目标与完整路径。没有有效结果则进入既有失败处理流程。
- 观测收益由候选位置发射有限数量射线，遇障碍或第一个未知格即停止；对首个未知格去重计数，按本轮有效候选归一化。目标朝向优先指向相邻未知区域。它是保守的可见未知边界代理，并非完整信息熵或对未知内部面积的预测。
- 射线视场、距离可配置；默认全周视场须与实际传感器覆盖核对。收益模型不替代机器人包络、未知区禁入和执行链安全校验。
- 失败候选进入独立、最多 100 条的冷却记录，不再当作成功访问追加惩罚。地图相关失败随地图内容版本改变失效；临时规划/导航失败在冷却到期后重试。成功到达仍记录访问历史。

以上路径比较与失败记忆属于探索协调器；独立 frontier_explorer 仍只是目标建议节点，未赋予其 Action 调度权限。

## 3. 默认参数

参数位于探索包 config，旧 autonomy 配置入口通过符号链接沿用。

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| search_result_max_age_sec | 2.0 s | 搜索快照最大墙钟年龄 |
| search_result_max_displacement_m | 0.25 m | 搜索期间最大允许位移 |
| completion_confirmations | 3 | 完成确认次数 |
| completion_stable_sec | 2.0 s | 同一内容版本的最小稳定时间 |
| max_candidates_per_cycle | 5 | 单轮规划候选上限 |
| selection_budget_sec | 8.0 s | 候选比较墙钟预算，检查粒度为协调器 tick |
| path_turn_weight | 0.2 | 累计转向角代价权重 |
| failure_cooldown_sec | 20.0 s | 失败候选冷却时间 |
| failure_radius_m | 0.35 m | 冷却匹配半径 |
| search.visibility_rays | 72 | 单候选观测射线数 |
| search.sensor_fov_rad | 2π | 观测视场 |
| search.gain_window_radius | 1.5 m | 保留原参数名，现表示射线距离上限；0 禁用收益 |

## 4. 已执行的离线验证

证据与验证程序放在 `/tmp/astribot-exploration-stage1/`，遵循架构文档中验证脚本放外部目录的约定。临时目录可能被清理，需要保留时应另行归档。

- `regression.cpp`：相同内容 1,000 次更新保持快照；膨胀前后的 30 个原始前沿不消失；年龄、位移、几何、当前前沿复检；完成迟滞、地图版本变化、时钟回退、新前沿、封闭未知；取消和非法地图状态。全部通过。
- `quality_regression.cpp`：实际绕行路径评分、角度跨 ±π、重复点、非有限路径；失败到期、版本失效与条数上限；可见未知朝向、墙体遮挡、取消与射线工作量上限。全部通过。
- ROS2 Humble 下构建 `astribot_autonomy_core`、`astribot_s1_exploration`、兼容包 `astribot_s1_autonomy`。

同一主机、单进程 C++17 `-O2`，每种尺寸预热 1 次、采样 100 次：

| 合成地图 | 平均 | P95 | P99 | 最大 |
| --- | --- | --- | --- | --- |
| 400×400 | 3.47 ms | 5.12 ms | 5.16 ms | 5.19 ms |
| 1000×1000 | 21.47 ms | 29.28 ms | 29.46 ms | 29.63 ms |

两组连续运行的进程峰值 RSS 16,820 KiB，包含地图、搜索对象和测试程序，不是单次搜索的独占内存。地图分辨率 0.05 m，右侧四分之一未知，已知区含多条有开口的墙；膨胀 0.35 m、每簇最多 8 个采样、射线距离 1.5 m。测试不包含 ROS 通信、TF、Nav2 规划及执行延迟，也未覆盖大量碎片前沿的最坏情况。

## 5. 后续验收与边界

现阶段保留全量搜索，避免在缺少实测瓶颈时引入增量缓存失效复杂度。上述数字仅为基线；接入实际地图回放后，以搜索 P95 < 100 ms、P99 < 200 ms 为初始目标，超标时再分析膨胀、可达域、射线和地图拷贝占比。增量方案须与全量参考实现逐图对照前沿集合和可达性。

尚未进行 ROS Action 延迟/乱序故障注入、仿真闭环或真机运动验收。下一阶段应在隔离仿真中比较覆盖率、总路程、目标切换数、重复失败次数、任务规划 P95，以及地图变化与取消竞态下的状态恢复；覆盖收益和路径效率不能由纯函数测试推断。此前“不发速度”的约束继续有效，本轮没有启动运动链路或发送导航目标。
