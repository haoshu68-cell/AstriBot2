# 虚拟墙、禁区与 SLAM 地图操作

本页是新功能操作说明。编译与隔离测试不代表 Gazebo/真机已验收；本次未控制真机。

## 建图期间

1. 启动本项目公共导航及建图链路，在工作站申请控制权，等待地图显示。
2. 暂停探索，取消导航或循环路线，等待状态确认停止。只收到取消受理还不能编辑。
3. 打开“虚拟墙与禁区”。选择虚拟墙、矩形或多边形；设置名称、墙宽、额外边距。
4. 点击“开始绘制”，在地图上点击。墙取两个端点，矩形取两个对角点；多边形逐点选取后点击“完成绘制”。“撤回一点”用于修正当前图形。自交、重复点、退化形状不能保存。
5. 选中列表可删除或启停。黄色表示草稿，红色表示服务端已有约束。删除和禁用同样需要保存，不能只看草稿颜色判断生效。
6. 核对位置并勾选确认，点击“保存并应用”。等待 `ZONES.READY`；`SAVED_WAIT_APPLICATION` 只表示写入成功，双代价地图及已启用的最终保护还需要确认。
7. 人工点击恢复探索或开始导航。区域内目标和穿越虚拟墙的路径受约束；软件不会自动驱动机器人退出自身所在的禁区。

退出绘制页会取消尚未完成的点列。已经完成但未保存的草稿仍保留在当前页；重启 RViz 不保存草稿。不要将“绘制出来”当作“已应用”。

## 存图与载图

- 探索结束或“取消探索并保存”沿用原有 mapping_session 收尾流程。
- finish 前冻结当前约束，和地图、关键帧一起写入地图目录内的 `manifest.json`。缺失当前会话的有效约束时，收尾等待并最终报告超时，不把未知约束当空集合保存。
- 原始 SLAM 地图不绘入虚拟障碍；探索使用约束后的地图副本，导航在 costmap 上叠加约束。
- 无目标但存在启用约束时保守报告 `BOUNDARY_LIMITED`，由操作员选择结束并保存部分地图，不自动宣称全图完成。
- 收尾后旧建图会话只读。通过“地图与工位”导入/载入保存目录，在完成定位校验后回到禁区页核对约束。首次从建图坐标继承的非空约束显示 `ZONES.REVIEW_REQUIRED`；确认并保存后才能开始任务。
- 后续重新加载同一地图版本自动恢复其禁区修订。多个业务场景共享该地图时共用禁区；换地图不会把旧墙带到新地图。新的建图会话独立建档。
- 不支持自动修正 SLAM 回环导致的旧墙坐标漂移，必须在最终地图上核对。发现漂移，删除旧区域并重绘后保存。

## 文件与迁移

统一存储位于地图管理器的 `storage_root/navigation_zones/zones.json`。默认是 `$XDG_DATA_HOME/astribot/map_catalog/navigation_zones/zones.json`；未设置 XDG 时为 `~/.local/share/astribot/map_catalog/navigation_zones/zones.json`。

它不在仿真日志目录内，也不依赖 RViz 配置文件。迁移完整地图目录时保留 `assets/`、目录索引以及 `navigation_zones/`；不要在节点运行时手改 zones.json。仅迁移原 SLAM 保存目录可恢复存图时的约束，不能带走后来对已加载地图做的修订。

## 异常提示

| 提示 | 操作 |
|---|---|
| NO_CONTEXT | 先启动建图会话或加载有效地图 |
| MAP_NOT_READY | 等待地图切换及定位验证结束 |
| WAIT_CONSUMERS | 检查双代价地图和启用的 final_protection 的状态与 TF |
| REVIEW_REQUIRED | 在当前地图上核对继承的区域，勾选后保存 |
| VERSION_MISMATCH / 页内版本冲突 | 重新加载服务端版本，再修改；不覆盖他人更新 |
| STOP_REQUIRED / STOP_OR_AUTHORITY_REQUIRED | 取得控制权，暂停探索，取消路线/导航并确认停稳；已存图会话需先加载地图 |
| 数据失联或来源冲突 | 排除故障后重新发起任务；不会自动续跑旧路线 |

## 部署与验收边界

运行时节点、Nav2 Layer、地图集成和 RViz 页面均为 C++。现有 Python/XML launch 负责装配。公共 navigation.launch 启用区域服务、双 costmap 和任务入口约束；若 `navigation_policy_stage=off`，只有规划/代价地图链生效，不存在独立的最终速度扫掠保护。真机需启用既有保护链并校验定位、完整包络、制动参数，不能据本次单元测试宣称物理围栏有效。

诊断录制增加 constraints/status/events/zone_markers 及区域服务参数。离线回放只允许区域 Marker 可视化，不向在线约束主题重放控制数据。
