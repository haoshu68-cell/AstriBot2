## 版本与证据边界

本版根据当前源码核对，Git 基点为 `9adddc4`，工作区包含未提交及新增文件，**该提交号不能单独复现本版实现**。部署时以 `deployment/source_manifest.json` 的逐文件哈希、构建记录及运行参数为准；不能仅以分支名、`current` 链接或历史文档标题识别运行版本。

本组手册首次编写时只整理文档和入口链接，未启动/停止仿真，未连接机器人、部署、申请 SDK 控制权或发送运动命令。命令检查只覆盖语法、帮助和启动计划预览，不是新的运动验收。

后续已补充[删包后的仿真回归](../AUTONOMY_SIMULATION_REGRESSION_20260917.md)：实际 Gazebo/RViz、短/完整导航路线及迁移入口验证。该回执按项目列明范围，不替代真机、双臂携物或完整策略阶段验收。整机架构新增建议也与当前已实现能力分开标注。

本轮导航路线 11/11 通过；SLAM 自主探索因候选全部被拒绝而未派发目标，未通过验收。后者是当前需排查的集成问题，不能用导航通过结果覆盖。

三种状态分开阅读：

- **代码存在**：实现或接口已在源码中。
- **入口启用**：指定 launch、配置和模式实际选择该实现。
- **验收通过**：有同一版本、场景和参数下的验证记录；不能从前两项推导。

## 当前操作要点

- 旧 `astribot_s1_autonomy` 兼容包已删除，当前共 19 个 ROS 包；组合调试入口改用探索包，见[迁移与验证记录](../AUTONOMY_PACKAGE_RETIREMENT_20260917.md)。

- 仿真基线显式用 `--mode baseline`：固定地图、真值定位、MPPI、0.35 m/s 轴向上限、策略 `off`、`simulation_precision`。
- 真机 `precision` 会重启感知/导航并使能底盘，之后等待人工目标；`explore` 会自动选择目标。无参数运行真机入口也会进入 `precision`。
- 用户到位要求为欧氏误差 ≤3 cm、最短角度误差 ≤1.5°；真值仿真精度档为 2 mm / 0.1°。配置阈值不等于真机已达到该精度。
- 两种精度档共用 `arrival_motion.yaml`；当前 `refine_timeout=135 s`，旧文档中的 45 s 不适用于这两个档位。`standard` 不加载该公共覆盖。
- 真机低速响应功能当前为 `monitor`，自动补偿 `compensate` 尚待真机验收。
- 85 cm 窄通道、通道外对齐阈值、通道内终点航向不可达契约仍有未完成项；不作为已交付能力。
- 当前源码已从项目目录启动地图自清和 TF 差分里程计脚本。机器人是否已使用该版本，需核对实际进程和部署清单。
