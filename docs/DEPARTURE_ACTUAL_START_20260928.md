# 脱困后按实际位置重新规划

用户 2026-09-28 要求：暂不进行脱困执行中的偏离校验，脱困结束后以实际位置作为正常导航的规划起点。本次仅改短段脱困控制，不扩展 SLAM 配准，不修改搜索、MPPI、正常到位算法或底盘保持参数。

## 执行链

`当前起点检查 → 必要时规划一个已检查的短段 → DepartureController 执行 → SLAM 相对位姿窗口确认停稳 → 重新获取实际位置/地图/包络 → READY → ComputePathToPose 从当前机器人位置规划目标路径`。

若复检仍要求脱困，原状态机会重新选择短段；该动作成功不能被当成整个起点准入成功。普通规划的 XML 没有设置 start 覆盖值，实际起点由规划服务查询；不传旧评估起点，不拿脱困计划终点当成实际终点。

## 实现范围

- 删除短段执行的横向/航向偏差、起点偏移、越程与终点横向不可达拒绝分支，以及无消费者的横向容差配置项。没有增加兼容开关或默认关闭的旧代码。
- 保留 Nav2 正常控制位姿的闭环跟踪。终点轻微越过时用限速的有符号位置反馈修正，最大平移速度仍为 0.05 m/s。
- SLAM 只承担该短段初始/结束的相对停稳证据；不再用独立 SLAM 局部坐标直接减去导航地图内的脱困起点。保留样本有效性、停稳、取消和原有执行预算。
- 控制进度使用正常控制反馈沿路径的进展；短段结束后的起点准入重新读取实际状态。
- `idle_position_hold=true`、`idle_position_kp=3.0` 保持不变。
