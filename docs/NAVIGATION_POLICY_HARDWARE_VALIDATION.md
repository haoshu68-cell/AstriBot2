# 真机验证接口与方案

真机资料不阻塞仿真阶段开发。仿真放行与真机放行分别记录；本文件不表示已完成真机验证。

## 参数与数据接口

`astribot_s1_navigation_policy/config/hardware.template.json` 是待填写模板。数值复制自仿真，`hardware_validated=false`；在参数来源和证据补齐前不可作为硬件运行配置。节点通过 `profile` 参数读取同一结构，使用 `use_sim_time=false` 时采用 ROS 时钟域。时钟对齐与重置使用独立 epoch，传感器的采集时间不能替换为推理/重发时间。

保留的输入为 `/odom`、地图、采集时刻 TF、配置的扫描话题、视觉观测话题、标定与 SensorHealth 领域接口。相机适配器输出米制框、像素框或无距离方位锥，携带相机/模型标识、标定版本、时间、几何不确定度与来源。没有有效深度时不能编造米制位置。视觉独有占据、不可定位观测、来源中断分别记录。

末级控制约束通过 `astribot_navigation_msgs/MotionConstraint` 传输。约束只限制现有命令；底盘驱动必须保留独立命令看门狗。当前仿真输出为 body-frame Twist，真机接线必须核对底盘接口单位、坐标系、方向及唯一发布者。

角运动分别配置 `max_angular_speed_rad_s`、`max_angular_acceleration_rad_s2` 和 `angular_brake_deceleration_rad_s2`；仿真沿用 1.5 rad/s、3.2 rad/s² 和 3.2 rad/s²。制动值仍需真机验证。`constraint_lease_s` 与 `input_command_timeout_s` 沿用 0.3 s，前者受消息协议 0.5 s 上限约束；它们与底盘驱动 `command_timeout_s=0.5` 的看门狗含义不同。硬件适配必须分别测量，不能只改一个超时参数。

## 必填证据

| 模板证据字段 | 验证内容 | 需要保留的记录 |
|---|---|---|
| `transport_envelope` | 运输姿态下包含双臂、夹爪的完整外形；所有允许运动方向和余转 | 机器人版本、关节姿态、测量轮廓、误差界、坐标系 |
| `payload` | 携物质量、尺寸、固定方式、摆动边界及是否遮挡传感器 | 每个受支持载荷工况及对应包络版本 |
| `braking` | 不同初速度、方向、载荷和地面的停止距离与余转；末级节点退出时的驱动响应 | 指令/实测速度曲线、命令看门狗时长、最差停止包络 |
| `latency` | 采集、推理、TF、融合、策略、执行器之间的实际延迟和抖动 | 对齐方法、原始时间戳、数据丢帧与超时记录 |
| `sensor_coverage` | 全身包络周围的有效观测范围、近场盲区、自滤与遮挡 | 雷达/相机外参、相机内参和深度单位、覆盖与失效条件 |

目标身份可靠性、运动估计窗口、预测不确定度与扫描有效比例均需结合实机噪声复核。不得仅把 `hardware_validated` 改为 true，或把 YAML 速度/减速度上限当作实际制动测量。

## 验证顺序

1. 只读采集：关节、TF、点云、视觉、里程计与时钟；验证 frame、单位、标定版本、覆盖和延迟。采用带哈希的参数快照。
2. 离线回放：实际数据输入策略，检查关联、静态背景误运动、遮挡保留、无深度、传感器冲突与迟到。先不接底盘输出。
3. 受控低速：按实际环境确定起始速度、隔离区域和独立急停；先验证全方向停车和末级节点退出，再扩大已证明的速度/载荷范围。
4. 分阶段闭环：复用仿真阶段场景，但以实测包络重新判定；包括横穿、迎面、堵路、局部/全局绕行、窄通道入口会车、出口阻塞、有限后退和动态载荷。
5. 基线回归：相同路线与工况重复测量航向/横向误差、速度/角速度平顺性、误停车、路径提交次数与到点精度。到点上限仍为 3 cm/1.5°；完成时间仅记录覆盖，不作为性能排序依据。

每个硬件场景保存设备/软件版本、参数哈希、原始数据、接触/间隙与停车记录、执行结果和人工复核记录。未验证的姿态、载荷、通道、速度不能继承其它工况的放行结论。

## 逐项操作工具

完整参数对照表、现场操作顺序、制动与独立到点误差计算见 [真机参数逐项验证操作手册](HARDWARE_PARAMETER_WORKBOOK.md)。配套 `tools/robot/validate_hardware_params.py` 提供 `init / record / mark / inspect / brake / arrival`；只读采集，参数副本与人工证据分开保存，不自动放行硬件。
