## “精度上限”的可计算部分

以下将“精度上限”理解为尽可能小的到位误差。确定误差的数学下界与可验收的误差上界是两件事。

理想无噪声、无死区的离散比例位置环，20 Hz、Kxy=0.5 时 e(k+1)=0.975e(k)，Kyaw=0.8 时角误差乘 0.96；误差理论上趋近 0，没有能从这些实验推出的非零极限。真实 Gazebo 还包含摩擦、轮速环、取样、TF 和速度平滑，因此零误差不是有限时间验收要求。

真机若也按 20 Hz 控制，最低已测档位一个周期产生约 0.1 mm 或 0.043° 的运动量；它们只是指令分辨尺度，不是到位保证。当前 SDK worker 目标周期为 4 ms（实际 dt 积分），名义对应 0.008 mm、0.0034°，同样不能抹去滤波尾程、反馈误差和地面滑移。

按本次最低档 braking 观测，平移附加路程约 1.3–1.6 mm，yaw± 余转约 0.39–0.45°。若同一接口同工况、控制周期 50 ms、从最低档直接停车且不做余程补偿，可以作“毫米级、约半度量级”的设计估算；单次样本极值不是概率保证或物理极限。预测停车、多次小幅闭环修正可能更好，但需真机实测。

还要计入轴间耦合：最低转速停车附带平移最高约 3.43 mm，最低平移速度停车附带转角最高约 0.134°。假设沿用同一 SDK 模式并由 20 Hz 导航控制，做一次“XY 停车后再 yaw 停车”的简单加法预算，则位置约为 1.58+3.43+0.10 = **5.12 mm**，角度约为 0.134+0.449+0.043 = **0.626°**。这是用于设计的观测极值预算，未包含定位误差、多次修正的相互影响，也不是统计置信上界。真机调参不能只看纯平移的 1–2 mm 尾程而忽略转动引起的位移。

真实位置误差预算：Ephysical ≤ Efeedback + Elocalization + Eframe/calibration + Epost-stop（各项必须在同一时刻/定义下避免重复计入）。真机缺独立定位/坐标标定误差和重复到位试验，故目前不能声称实机达到 2 mm 或其它确定上限。

## 仿真到位控制

仿真工程验收目标设为欧式误差 ≤2 mm、角误差 ≤0.1°。进入停止状态用验收阈值的 65%（1.3 mm、0.065°），误差离开 90%（1.8 mm、0.09°）才重新修正；XY 与 yaw 分开保持，避免单轴在另一轴收敛时反复开停。连续 0.6 秒低速、位姿漂移 ≤阈值的 20%，且源时间推进后才报告成功。所有最终零速/修正命令仍做足迹碰撞检查。

参数由 navigation.launch.py 的 simulation_precision 档位覆盖，且必须 use_sim_time=true；一键启动仅 baseline（ground_truth）模式自动选用。SLAM 仿真默认 standard，避免将真值定位下的阈值直接用于带噪定位；硬件仍保留 3 cm/1.5° 验收值和原速度上限。捕获半径以外的 ThreePhaseController、路径规划及跟踪增益不修改。首轮实跑仅收紧阈值，在约 8.04 mm 处卡住并触发无进展异常；驱动轮速环仅在目标轮速 >0.05 rad/s 时启用摩擦前馈。精度档位加入仿真专用 0.008 m/s、0.02 rad/s 末端最低指令，来源为仿真低速失动观测及轮速模型，不沿用 SDK 档位。指令仍受速度约束缩放、最大值及碰撞检查约束，进入保持后输出零。平移尚未保持时使用 0.01 rad 的粗航向容差，位置保持后再切入精细角度容差，减少轮子平移扰动带来的左右修正；粗航向容差不能用于成功验收。

仿真微调最低指令在 20 Hz 下对应每周期 0.4 mm、0.057°。实际还存在执行/TF 延迟和摩擦，故选择 2 mm/0.1° 作为有裕量的工程目标，不将离散步长或最优单次结果称作物理精度极限。

不计低速补偿，从捕获半径 0.3 m、0.06 m/s 上限到 1.3 mm，理想比例环约需 12 秒；这是预算估算，不是耗时考核。保留 45 秒 refinement 超时及无进展检测。

## 真机验证接口

在原现场条件记录基础上，以独立测量工具/视觉标记验证 base 坐标：每方向至少 20 次到同一目标，记录停车后 1、3、10 秒位置/角度误差、最大值/P95/重复性、反向次数；负载和地面分组。先检验厂家 wz 偏置，再分别以 SDK 和实际导航 cmd_vel 链路复测。视觉/mark/SLAM 仍通过 ArrivalController 原有 base pose 接口输入，必须带正确坐标系和源时间戳。

## 更紧阈值试验的取舍

另测了 1 mm 位置容差与 0.015 rad/s 最低转速组合，首目标最终位置 0.651 mm、角误差 0.164°，因为末端低速失动及长时间小范围修正触发 Nav2 进展超时，未通过。两个参数同时变化，不能据此证明 1 mm 物理不可达。最终保留 2 mm / 0.1° 容差、0.02 rad/s 最低转速，并采用先粗后细航向策略，优先避免反复微动。无进展与超时保护没有被关闭或放宽。
