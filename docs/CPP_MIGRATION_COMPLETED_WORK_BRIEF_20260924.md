## 2. 性能量化

同一行采用对应阶段的同输入对照；P95 表示 95% 样本不超过该延迟。不同模块的采样窗口和负载不同，不能相加或换算为整机提速。

| 模块／场景 | 指标 | Python | C++ | 延迟下降 |
|---|---|---:|---:|---:|
| fixed_v2 包络提案 | 服务往返 P95 | 2.499 ms | 0.296 ms | 88.1% |
| 几何状态：空载 | 采集到发布 P95 | 34.297 ms | 7.272 ms | 78.8% |
| 几何状态：偏置载荷 | 采集到发布 P95 | 39.139 ms | 20.105 ms | 48.6% |
| 臂底盘耦合 | 输出延迟 P95 | 0.715 ms | 0.357 ms | 50.1% |
| 导航仲裁：假 Nav2 | 提交至终态 P95 | 24.886 ms | 6.245 ms | 74.9% |
| 地图中继：1024² | 延迟 P50 | 65.959 ms | 1.973 ms | 97.0% |
| 策略观测候选：64 目标 | tick 处理 P95 | 3.963 ms | 0.573 ms | 85.5% |

资源占用方面，臂底盘耦合 CPU 中位数由 5.40% 降至 0.85%，常驻内存由 65.90 降至 24.11 MiB；导航仲裁 CPU 由 5.28 降至 0.40 ms/任务，常驻内存由 64.12 降至 26.62 MiB。

保留性能例外：耦合最大单条延迟 3.784→3.933 ms，小地图最大单条延迟 6.161→10.436 ms；几何完成通知优化增加约 0.223 个百分点的单核 CPU 使用。不能宣称所有场景、所有样本均更快，短窗口内存数据也不证明长期无泄漏。
