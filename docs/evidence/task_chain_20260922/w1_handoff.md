# W1 本轮实施与接续说明

计时：2026-09-22 00:52:43.971536 至 02:22:43.971536（北京时间）。重试没有重新计时。总状态以 implementation_status.json 为准；下列子项通过不表示 W1 整体验收。

## 已实施的数据流

原生 Gazebo 双腕 RGB / depth / CameraInfo → C++ 腕相机会话门控 → 私有 active 流 → 现有 C++ 同戳配对、健康与点云。头部和腹部连续观测链保持原有职责。会话服务只管理感知资源，不授权机械臂或底盘运动。

- 服务：`/perception/camera_session/{left_wrist_rgbd,right_wrist_rgbd}/set`；状态在去掉 `/set` 的同名话题。
- 任务提供 owner_id、execution_id、唯一 request_id；ACQUIRE 返回 session_token，后续 RENEW/RELEASE 必须匹配。
- 租约最长 2 秒，请求有效期 250 毫秒；ROS 时间和单调墙钟同时限制。停钟、回退、到期、释放均停止有效输出。重复 ACQUIRE 不延长租约。
- activated_at 隔离不同会话。旧拍摄时间不能用于新会话；健康有效期不超过相机会话有效期。
- 每条流的等待队列限制为 1～4 帧；微小的图像/时钟到达顺序差通过有界等待解决，图像仍在未来时绝不发布为当前有效观测。
- 同一代未来心跳先缓存，不覆盖尚有效的状态；撤销、缩短有效期和代际变化立即处理。
- 大图像复用现有 Fast DDS 图像桥接配置；未放宽 250 毫秒新鲜度要求。最新启动修复将显式配置传给整个腕部处理链，并用作用域避免影响外部环境。

边界：合作式 owner/token 不等于访问认证；未完成全局唯一服务提供者准入。当前控制 ROS 订阅和处理，不关闭 Gazebo 渲染或传感器电源。完整任务阶段的 C++ 客户端仍需接入。参考外参仍非真机标定。

启动层：六相机透传与不合法配置提前拒绝 3 项；显式 DDS 配置到达转发/健康点云两侧且不外泄 2 项。后一项先复现失败再修复；使用替代进程观察真实 launch 环境，不启动机器人。该启动修复晚于当前 v6 运行安装，持续采集使用已统一设置的外层 DDS 环境，不能算作新版独立启动闭环验收。

10 分钟 DDS 对照消除了四路 RGB-D 的 STALE/RATE_LOW，但老版心跳仍有 11 个腕部 INACTIVE 样本。下一档消除了 INACTIVE，仍有 7 个 STALE 样本（支持服务加载/构建扰动）。这些失败全部保留，不因录制完成而判通过。最新 v6 和计算压力数据见各 analysis JSON。

实际导航：旧消费者安装缺失 V2 确认已通过隔离构建修正。最后一次两个紧凑姿态执行成功，包络确认成功；第一个导航目标被拒绝，尚无 MPPI 运动通过。禁行区返回 ZONES.NO_CONTEXT，实际地图管理器没有源码新增的 simulation_static_map_yaml 参数。手动会话也没有 social_sim 物理几何记录，不能完成通道净空评估。原外层缺样本超时掩盖 ACTION_REJECTED，现已修正并对保存记录重算，旧记录不覆盖。

当前仿真使用静态地图/真值定位；VOXEL SLAM 计算仍随 launch_slam=true 启动，其地图和 map→odom 发布关闭。不能称为 SLAM 定位闭环。GraspNet 压力档使用冻结的旧点云和真实 C++ CUDA worker，仅为计算负载，不验证当前相机识别、候选质量或抓取执行。

## 接续顺序与放行条件

1. **先整理可重复的导航运行安装。** 比较当前地图管理器源码/安装和静态地图上下文测试，在新的隔离目录构建当前依赖闭包，冻结实际 ELF 和 launch 文件。不要覆盖其他会话安装。确认静态地图上下文、zone token 和全部消费者 ACK 后才发导航目标；不得关闭区域保护绕过拒绝。
2. **补齐物理通道场景。** 使用既有 run_regression 的场景启动路径，加载 case.scene，确认 /social_sim/state 的实际几何、拍摄时刻 TF、轮速、包络与策略连续记录。只有生命周期 active 不足以开始运动验证。
3. **重跑 MPPI 运动档。** 先加载支持服务并停稳、再开始相机窗口和现有仲裁协议。检查原地准备/入口调整/通道/出口；失败与 FOLLOW、终止阶段指标分开；完整三维凸包净空不小于既有门槛，不能放宽验收。
4. **补完整 W1 矩阵。** 分别记录相机单独、SLAM 计算、实际 MPPI 运动、推理与全并发；正常档至少 10 分钟，压力档 30 分钟。包括各角色 ROI/盲区、流丢失/乱序、时钟、TF、重启与 GPU 忙的能力撤销和新 epoch 恢复。记录内部各阶段延迟及队列峰值；观察端 age 不能替代这些指标。
5. **W1 放行后进入 W2。** YOLO/真实掩码到物体点云，然后 W3 多视角已知 CAD 6D、W4 物体身份与世界版本、W5 原始 READY_RIGHT/MTC 场景、W6 三维覆盖和 W7 多负载规划对照。W9 C++ 迁移/长稳随任务推进。VLA、真机、完整动态抓取搬运放置仍暂缓。

每个后续任务独立记录实际开始时间；失败重试不重置 90 分钟。不能跳过未放行项来宣称整条任务链完成。
