## 文件与复现

- `analyze_ground.py`：独立离线分析脚本，仅需 NumPy/SciPy，无 ROS 依赖。
- `ground_analysis.json`：输入哈希、重组约定、全量统计、平面参数、收敛标记和敏感性。
- `merged_map_xyz.pcd`：可复用合并点云，binary PCD，XYZ float32；点次序为数值 keyframe id 顺序、各源 PCD 原始点顺序。
- `run_output.json`：最近一次运行的精简输出。
- 合并 PCD SHA256：`9470541968b5d9af91525ed9287759ca9db848be6f30123deef816148abdc391`。

  /home/yjh/WorkSpace/astribot_sdk_ros2/runs/slam_unification_20260918/sessions/sim_unified_15 \
  /tmp/sim_unified_15_ground_reproduction

独立几何核验：源 PCD 点数和、输出 header、JSON 均一致；二进制载荷 16,051,308 字节等于点数乘 12。用独立四元数向量公式抽查 `9.pcd` 首点与 `1603.pcd` 首点，结果与输出对应 float32 逐位相同。该核验只验证重组，不证明地面真值。PCD 默认 VIEWPOINT 和二维地图 YAML 的 origin 第三项（yaw）都不能当地面高度。
