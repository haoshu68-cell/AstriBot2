# 评审技能验证记录

日期：2026-09-22。范围：技能格式、引用和基于虚构材料的使用检查。没有运行 ROS/Gazebo 或硬件验收，没有修改被评机器人源码。输入版本见 [source_snapshot.json](source_snapshot.json)。

## 基线试评（新增技能前）

一名子代理只读取既有 `astribot-architecture-design` 和 `robotics-validation-evidence`，评审两道虚构题：

1. MTC/Action 成功被扩张为抓持成功；真值定位的仿真到点被扩张为实机 2 mm；保存区域被扩张为已经应用；共识被视为真问题；均值改善掩盖尾延迟和取消缺口；单一 SSM 距离阈值被用来声称满足 ISO。
2. 新鲜度阈值仅写 0.25，单位/时钟不全；A/B 均值 3/2 ms、P95 4/6 ms；7 场景只有 clear/far 输出；600 秒测试被其他任务仿真负载干扰。

观察结果：已有技能已能识别上述主要证据越级，要求阈值两侧和等值测试、独立判据以及性能分位数对照。这不是一个“旧技能全部失败”的基线，也不把这些能力归功于新增技能。

具体仍缺的结构：输出没有稳定的 R/C/F/SC/E 关联表、可直接复用的场景卡和项目入口目录。第二题将需补参数的卡片整体标 blocked，没有给出同一场景中可以独立推进的步骤。新增技能通过模板字段和按依赖分解处理这些缺口，不积累无关禁止规则。

## 加载后使用检查

同一子代理读取新增三个技能及相关模板，使用上述题设，并补充明确的样本龄期/接收龄期各 <=0.25 s、源/单调时钟、1 ms 注入精度。同时给出一个正确受限的只读同步诊断声明，检查是否为了挑错而虚构缺陷。

输出要求：可追溯评审、任务取消/相机/姿态三张场景卡、性能与 ISO 结论，未知参数保留未知，允许推进不依赖缺失项的工作。输出仅写临时文件，不触碰机器人代码或运行环境。

检查维度：

- 只读边界和资料版本诚实；
- 共识/分歧/单方问题均求证，缺证据不伪装已复现；
- R/C/F/SC/E 能关联，判据与证据层明确；
- 等值边界、时序竞争、禁止行为、恢复及资源归属有记录；
- 预期拒绝与业务成功、均值与尾延迟、软件与硬件分别判断；
- 肯定题设已有支持的受限声明，不强行制造问题；
- 未运行状态、缺参数和可独立继续部分明确。

实际输出已读取并保留为 [forward_review.md](forward_review.md)。该子代理与基线为同一评审者，先后调用且题设补充了时间参数，因此不是盲测或可用于计算提升率的对照实验。
完整输出等待过长后进行了收尾限制，最终取得已写出的三张场景卡及简短反馈；没有将等待过程计为试评通过。

| 检查项 | 观察结果 |
|---|---|
| 只读范围 | 输出声明仅用题设、未读示范答案；没有运行机器人测试；未知 hash 保留 UNKNOWN |
| 追溯关系 | 给出 R/C/F 及 E 题设证据、SC 和未生成的计划证据；未把规划证据路径冒充存在的实验 |
| 取消竞争 | 包含晚接受、晚成功、同刻事件两种排序和过期/重放；不一律强判 CANCELED；注入停稳反馈不冒充实测 |
| 时间边界 | 两个时钟分别计算，249/250 ms 接受、251 ms 拒绝；给出9格组合与时间推进用例 |
| 姿态统计 | 区分有效输出、拒绝正确性、误拒绝与业务成功；无标签/真值时不判准确率 |
| 性能/标准 | 不用均值掩盖 P95；未给预算不武断判超预算；不编造 ISO 通过/条款 |
| 公平核查 | 支持题设只读诊断的限定协议声明，没有强加物理曝光或整机验收责任 |
| 局部阻塞 | 缺实测参数时仍设计确定的时间边界、事件序列和响应观测 |

试评给出的 10秒夹具上限、重复3次等明确标为计划建议，不是项目验收要求。相机39条指13条主轨迹各3次，恢复作为后置检查；这些测试未执行，不形成实际通过数。

发现并修正的模板歧义：原模板将 NOT_RUN 与 BLOCKED 放在同一状态栏。现在分为 `readiness=READY/BLOCKED/N_A` 与 `execution=NOT_RUN/PASS/FAIL/INVALID/N_A`，局部可执行项拆开记录。主技能和模板均已同步。

定向复核回复给出三种正确状态对：缺参数未运行为 BLOCKED/NOT_RUN；开跑时就绪但夹具失败为 READY/INVALID，复测准备可另记 BLOCKED；正常执行成功为 READY/PASS。按其建议，模板补上 readiness 评估时刻和每个 run_id 的开跑快照，避免复测状态覆盖原始轮次。

结论：文本试评覆盖了所列主要使用规则；本轮不是大样本、独立评审团或机器人验收，不能据此推导技能没有任何遗漏。
